# Rubik's Cube

**6/2022 - Marko Vučić**

A 3x3x3 Rubik's cube rendered with deferred shading. Each layer can be turned individually,
the cube can be scrambled with one button, and it has a "neon mode" where the sticker edges
light up and cast real colored light onto the desk it sits on.

## Controls

Hold left mouse button -> look around  
Mouse scroll -> zoom  
Arrow keys -> move the camera forward/back/left/right  
Page Up / Page Down -> move the camera up/down  
U / F / R / L / D / B -> rotate the corresponding face  
Alt + (U / F / R / L / D / B) -> rotate that same face the other way (e.g. Alt+U = U')  
N -> trigger the neon event sequence (see below)  
F1 -> show/hide the GUI panel  
Esc -> quit  
"Scramble the cube" button (in the GUI) -> plays 20-30 random moves; manual face rotation is
locked out until the scramble finishes

## Features

### Fundamental:

[x] Model with lighting  
[x] Two types of lighting with customizable colors and movement through GUI or ACTIONS - a
room point light and a lamp spotlight, both with position/color/cutoff sliders in the GUI,
and the lamp is aimed with a fixed direction vector rather than always tracking the cube  
[x] ACTION_X (pressing N, or the "Turn neon on" button) ---AFTER_M_SECONDS(M=1.5s)---Triggers--->
EVENT_A (room/lamp lighting fades out while the neon look fades in) ---AFTER_N_SECONDS(N=4s)---Triggers--->
EVENT_B (the neon glow starts pulsing/breathing). Every trigger in the chain is logged to the
console as it fires.

### Group A:

[x] Frame-buffers with post-processing  
[ ] Off-screen Anti-Aliasing  
[ ] Parallax Mapping  
[x] Bloom with the use of HDR - two-attachment HDR framebuffer, separable Gaussian blur over
ping-pong buffers

### Group B:

[x] Deferred Shading - a geometry pass fills a G-buffer (world position + neon mask, world
normal, albedo + specular), and a full-screen lighting pass reads it back once per pixel.
This is also what makes possible to give every one of the cube's 54 stickers its own point
light when neon mode is on, instead of just faking the glow with bloom alone.  
[ ] Point Shadows  
[ ] SSAO

### Engine improvement:

`PostProcessController` (`engine/graphics/PostProcessController.hpp`) - HDR capture, bloom
blur and tonemap/composite, with tunable exposure and blur passes/spread.  
`GBuffer` (`engine/graphics/GBuffer.hpp`) - owns the G-buffer framebuffer and its textures for
the deferred shading pass, plus the full-screen quad the lighting pass draws with.

## Models:

`sub_cube.obj` - hand-written, plain unit cube used for every cubie  
`sphere_core.obj` - hand-written, sits inside the cube so the gaps between cubies don't look hollow  
`desk.glb` - .glb downloaded model of a desk - did not infer color from it\
`lamp.glb` - .glb, same as desk model

## Textures

The cubie's diffuse/specular/normal maps are generated by a small script rather than authored
images - the specular and normal maps mark out the neon tube band using the same edge-distance
formula the shader itself uses for the glow, so the tube's shininess and bump line up with
where it actually glows.
